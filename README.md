# Dummy-Super-Market-Data
**Power BI Dashboard - Superstore Data Analysis**
This repository contains a Power BI dashboard project that analyzes the Superstore dataset sourced from Kaggle. The dataset provides detailed information about orders, customers, products, and financial transactions across different regions.

**Dataset Overview:**

This datase from kaggle contains all atributes of super store in U.S.

**Order details** Order ID, Product ID

**Product information** Category, Subcategory, Product Name

**Customer details** Consumer name, Segment (Corporate or Consumer)

**Location data** Region, City, State, Postal Code

**Shipping information** Shipping modes, shipping costs

**Financial metrics** Sales, Discounts, Profit, Quantity

**Dashboard Features:**
Visualizes total sales by Region and Segment using pie charts and donut charts for easy comparison.
Displays shipping mode analysis, highlighting cost variations between shipping options.
Bar charts track sales trends over time, broken down by Category, Subcategory, Yearly and Quarterly timelines.
Key financial indicators are presented through cards showing sum of sales, profit, quantity sold, and discounts applied.

This dashboard helps business users gain insights on sales performance, shipping cost impact, and customer segments for data-driven decision making.
Provides info. about orders, customers, products, finance. Has Order, Product, Customer, Location, Shipping, Financial info. It Visualizes sales by Region, Segment using pie, donut charts for comparison. Shows shipping analysis, cost variations. Bar charts track trends, by Category timelines. KPI's shows sum of sales, profit, quantity, discounts .
